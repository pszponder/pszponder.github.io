Obsidian-Style Callouts Now Available!

August 16, 2025 4-minute read
Guide
Obsidian • Callouts • Admonitions • Markdown • Guide

Obsidian-Style Callouts Now Available! Link to heading

Great news! This site now supports native Obsidian-style callouts using the excellent hugo-admonitions module. You can now write callouts exactly as you would in Obsidian!

Quick Start Link to heading

Simply use the standard Obsidian syntax:

[!NOTIFY] System notification: Your password will expire in 30 days.

The above callout will render beautifully with proper styling and icons!

Basic Callout Types Link to heading

Here are the most common callout types you can use:

Information & Notes Link to heading

[!NOTE] This is a note callout - perfect for general information and context.

[!INFO] Use info callouts to provide helpful background information or explanations.

[!ABSTRACT] Abstract callouts are great for summaries and overviews.

Tips & Guidance Link to heading

[!TIP] Pro tips and helpful tricks go in tip callouts like this one!

[!IDEA] Got a creative idea? Share it with an idea callout.

[!GOAL] Use goal callouts to highlight objectives and targets.

Warnings & Alerts Link to heading

[!WARNING] Warning callouts alert readers about potential issues or important considerations.

[!CAUTION] Use caution callouts when readers need to be extra careful about something.

[!IMPORTANT] Mark critical information that readers absolutely must not miss.

Status Indicators Link to heading

[!SUCCESS] Celebrate positive outcomes and completed tasks with success callouts.

[!ERROR] Document errors, failures, and problems that need attention.

[!DANGER] Use danger callouts for critical warnings about irreversible or harmful actions.

Custom Titles Link to heading

You can customize the title of any callout:

[!TIP] Pro Development Tip Always version control your configuration files - you’ll thank yourself later!

[!WARNING] Breaking Change Alert Version 3.0 introduces breaking changes to the API. Please review the migration guide.

[!SUCCESS] Deployment Complete Your application has been successfully deployed to production!

[!QUESTION] Got questions? Use question callouts for FAQs and inquiries.

[!TASK] Track action items and tasks that need to be completed.

[!MEMO] Quick memos and reminders can be highlighted this way.

Content Organization Link to heading

Compatibility with Obsidian Link to heading

The best part? These callouts use the exact same syntax as Obsidian! This means:

  • ✅ Copy and paste between Obsidian and your blog
  • ✅ No need to learn Hugo-specific shortcodes
  • ✅ Your existing Obsidian notes work immediately
  • ✅ Consistent workflow across tools

Real-World Example Link to heading

Here’s how you might use callouts in a technical blog post:

[!INFO] Context We’re building a data pipeline that processes customer events in real-time.

[!WARNING] Important Consideration Make sure your Kafka cluster can handle the expected throughput before deploying.

[!CODE] Implementation

def process_events(events):
    return events.filter(valid).transform(normalize).save()

[!SUCCESS] Result The pipeline now processes 10,000 events per second with 99.9% uptime!
